NPC 설정

글을 고친 뒤에는 그 칸의 저장 버튼을 눌러야 파일에 적힙니다(체크 상자는 바꾸면 바로 저장). NPC의 다음 대답부터 적용되고, 앱을 다시 켤 필요가 없습니다.

대답 모델 · 닉네임 인식

이 기능은 업데이트된 음성 앱을 다음에 시작할 때 사용할 수 있습니다.

기본은 Haiku 5.5입니다. 저장하면 다음 대답부터 적용됩니다. 이미 만들고 있는 대답은 기존 모델로 마칩니다. AI 꺼짐·가짜 AI 모드에서는 선택만 저장합니다.

프롬프트 캐시는 모델별입니다. 다른 모델로 바꾸면 기존 모델의 캐시를 공유하지 않고 새 모델의 캐시를 만듭니다.

대답 1회 예시 비용 (USD)
모델캐시 생성캐시 재사용

고정 입력 3,000 + 나머지 입력 1,000 + 출력 200토큰, API 호출 1회, 5분 캐시 가정입니다. 실제 청구액이 아니며 추가 thinking·검색·재시도·세금은 제외합니다. Opus는 thinking을 끌 수 없어 추가 출력 비용과 시간이 들 수 있습니다. Haiku 입력 10만 토큰 초과는 다른 요금입니다. 요금 출처 (2026-11-19 확인).

기본은 낮음입니다(지금까지와 같음, 가장 빠름). 높일수록 대답하기 전에 더 오래 생각해서 느려지고 비용이 늘어납니다. 보통 이상에서는 모든 모델이 대답 전에 생각을 하고, 매우 높음·최대는 몇십 초가 걸릴 수 있습니다. Haiku·Sonnet·Opus 5.5 모두 다섯 단계를 쓸 수 있습니다.

한 줄에 이름 하나 또는 인식된 말 -> 바꿀 말. 예: 404 -> 사공사는 인식 결과의 404를 사공사로 바꿉니다. 반대를 원하면 사공사 -> 404로 적으세요. 양쪽 이름을 Whisper 어휘 힌트로도 전달합니다. 최대 32줄, 양쪽 각각 80자, 전체 2,048자. 비워 저장하면 해제됩니다.

두 NPC의 잡담

두 NPC에 공통으로 적용됩니다. AI가 꺼져 있거나 일일 한도에 도달하면 준비된 대사를 사용합니다.

1. 성격

NPC가 어떤 아이인지 적은 글입니다(). 이름, 말투, 좋아하는 것, 주변에 있는 물건을 자유롭게 고쳐 보세요.

이름을 바꾸면 아래 글의 "이름:" 줄도 함께 바뀝니다.

글이 길수록 대답 한 번의 비용이 조금씩 늘어납니다.

고정된 대답 규칙 보기 (읽기 전용)

"한국어로 짧게" 같은 기본 규칙입니다. 바꾸려면 persona_ai.py의 RULES를 고쳐야 합니다.


    

    

      AI에게 실제로 보내는 글 전체 보기 (읽기 전용)
      
규칙 + 성격 + 오래 기억하는 것 + 지금 말하는 사람에 대한 인상을 합친 글입니다. NPC는 대답할 때마다 이 글과 최근 대화를 함께 봅니다.

      

    

  


  

    
2. 플레이어를 어떻게 생각하는지

    
NPC가 사람마다 적어 두는 짧은 인상 메모입니다. 대화하다가 인상이 달라지면 NPC가 스스로 고쳐 씁니다. 직접 고쳐도 됩니다.

    

    
    

    

      
      
    

    

  


  

    
3. 기억

    
오래 기억하는 것

    
앱을 껐다 켜도 남는 메모입니다(최대 개). NPC가 "기억해 둘 만하다"고 느낀 것을 스스로 적기도 합니다. 많이 쌓이면 아래 "기억 자동 정리"가 합쳐서 줄이고, 정리를 꺼 둔 채 가득 차면 NPC가 적은 것 중 가장 오래된 것부터 지워집니다.

    

    

      
      
      
    


    
기억 자동 정리

    
메모가 많이 쌓이면 NPC가 대답을 마친 뒤에 조용히 한 번 정리합니다. 겹치는 내용은 합치고 사소한 것은 빼서 절반쯤으로 줄이며, 이름·취향·약속 같은 사실은 남깁니다. 대답 속도에는 영향이 없고, 한 번에 약 0.002달러(2~3원) 안팎입니다(Haiku 5.5 사용).

    
이 기능은 업데이트된 음성 앱을 다음에 시작할 때 사용할 수 있습니다.

    
    
    
    
    
    
    
    
    
    
    

      
      
      
    

    


    
최근 대화
